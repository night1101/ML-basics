# Логистическая регрессия: Logit vs Probit

## 📌 Описание задачи
Сравнение бинарной и мультиномиальной логистической регрессии для классификации данных о недвижимости.

**Целевые переменные:**
- `expensive` (бинарная) — цена выше/ниже медианы
- `view` (мультиномиальная, 5 классов) — качество вида из дома

**Основные вопросы:**
1. Сравнить Logit и Probit модели — какая лучше?
2. Насколько хорошо модель предсказывает качество вида?
3. Какие классы `view` предсказываются хуже всего?

## 🧠 Используемые методы
- **Logit** — логистическая регрессия (sklearn)
- **Probit** — пробит-регрессия (statsmodels)
- **Мультиномиальная логистическая регрессия** (multinomial)
- **Accuracy** — точность классификации
- **Log-Likelihood** — логарифмическое правдоподобие
- **Confusion Matrix** — матрица ошибок
