# Линейная регрессия (OLS) и взаимодействия признаков

## Описание задачи
Построение модели линейной регрессии для прогнозирования цены дома на основе данных `kc_house_data.csv` (цены на жильё в округе Кинг, США).

**Целевая переменная:** `price` — цена дома

**Основные вопросы:**
1. Какие признаки наиболее значимо влияют на цену?
2. Улучшит ли качество модели добавление взаимодействий между признаками?
3. Есть ли переобучение при добавлении сложных взаимодействий?

## Используемые методы
- **OLS** (Ordinary Least Squares) — классическая линейная регрессия
- **Взаимодействия признаков** — произведение числовых признаков на дамми-переменные
- **p-value анализ** — оценка статистической значимости коэффициентов
- **R² и Adjusted R²** — метрики качества
- **Train/Test split** — проверка на переобучение

## Результаты

| Модель | R² на обучении | R² на тесте | Разница |
|--------|----------------|-------------|---------|
| Без взаимодействий | 0.6870 | 0.6893 | +0.23% |
| С взаимодействиями | 0.7049 | 0.7037 | -0.12% |

**Ключевые выводы:**
- Самые значимые признаки: `waterfront`, `grade`, `sqft_living`
- Добавление взаимодействий улучшило R² на **1.72%**
- Модель с взаимодействиями показала меньшее переобучение
