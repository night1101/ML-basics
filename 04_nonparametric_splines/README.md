# Непараметрическая регрессия: Сплайны и GAM

## Описание задачи
Сравнение различных методов аппроксимации сложной нелинейной функции на синтетических данных с шумом.

**Истинная функция:**
f(x) = exp(-x²) - exp(-(x-2)² / 8)
**Выборка:** N = 50 точек, шум σ = 0.2

## Используемые методы
- **Полиномиальная регрессия** (Ridge, CV выбор степени)
- **B-сплайны** (фиксированные узлы, с/без сглаживания)
- **Сглаживающие сплайны** (узлы в каждой точке X)
- **GAM** (Обобщённые аддитивные модели, pygam)

## Результаты

| Метод | MSE | Степени свободы (df) |
|-------|-----|---------------------|
| **GAM** | **0.00497** | 25.0 |
| B-Spline (Smooth) | 0.01135 | 23.0 |
| Smoothing Spline | 0.01405 | 9.0 |
| B-Spline (Fixed) | 0.01267 | 8.0 |
| Ridge Polynomial | 0.09797 | 2.0 |

**Ключевые выводы:**
1. **GAM показал лучший результат** (MSE = 0.00497)
   - Адаптивно подбирает степень гладкости
   - Не требует ручного выбора узлов
   - Находит оптимальный баланс между смещением и дисперсией

2. **Сплайны с фиксированными узлами** без сглаживания переобучаются
3. **Полиномы высоких степеней** сильно переобучаются (MSE ≈ 0.1)
