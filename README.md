# Machine Learning Fundamentals

Этот репозиторий содержит мои учебные проекты по основам машинного обучения.  
Здесь представлены как параметрические (линейная/логистическая регрессия), так и непараметрические методы (сплайны, гауссовские процессы).

## Содержание
1. **Линейная регрессия** (`01_linear_regression`)
   - Прогнозирование цен на жильё (датасет `kc_house_data`).
   - OLS, анализ значимости признаков, R².

2. **Логистическая регрессия** (`02_logistic_regression`)
   - Бинарная классификация (дорогой/дешёвый дом).
   - Мультиномиальная классификация (качество вида дома).
   - Сравнение **Logit** и **Probit** моделей.

3. **Регуляризация и отбор признаков** (`03_regularization`)
   - Сравнение **Lasso** и **Ridge** регрессии.
   - Анализ синтетических данных (Lasso обнуляет незначимые признаки).
   - Сравнение с пошаговым отбором (Stepwise).

4. **Непараметрическая регрессия (Сплайны и GAM)** (`04_nonparametric_splines`)
   - Полиномиальная регрессия (Ridge).
   - B-сплайны и сглаживающие сплайны.
   - **GAM** (Обобщённые аддитивные модели) — наилучший результат.

5. **Непараметрическая регрессия (Ядра и ГП)** (`05_nonparametric_kernel_gp`)
   - **Ядерное сглаживание** (Kernel Regression).
   - **Гауссовские процессы** (Gaussian Process) для регрессии.
   - Получение доверительных интервалов.

## Технологии
- Python 3
- NumPy, Pandas, Matplotlib
- Scikit-learn (LinearModel, Lasso, Ridge, LogisticRegression, GaussianProcess)
- Statsmodels (OLS, Logit, Probit, KernelReg)
- PyGAM
