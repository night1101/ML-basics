# Непараметрическая регрессия: Ядерное сглаживание и Gaussian Process

##  Описание задачи
Сравнение двух непараметрических методов регрессии: ядерного сглаживания (Nadaraya-Watson) и гауссовских процессов (GPR).

**Истинная функция:**
f(x) = exp(-x²) - exp(-(x-2)² / 8)
**Выборка:** N = 50 точек, шум σ = 0.2

##  Используемые методы
- **Ядерное сглаживание** (KernelReg) — непараметрическая регрессия с автоматическим подбором ширины окна
- **Гауссовский процесс (GPR)** — байесовский метод регрессии с оценкой неопределённости
- **Кросс-валидация** — выбор оптимального ядра и гиперпараметров

##  Результаты

| Метод | MSE | Преимущества |
|-------|-----|---------------|
| **Gaussian Process** | **0.00278** | Доверительные интервалы, байесовский подход |
| Kernel Regression | 0.00759 | Простота, скорость |

### Сравнение с методами из дз4

| Метод | MSE |
|-------|-----|
| GAM (дз4) | 0.00497 |
| **Gaussian Process** | **0.00278** |
| Kernel Regression | 0.00759 |
| Smoothing Spline | 0.01405 |


**Ключевые выводы:**
1. **Gaussian Process показал лучший результат среди всех методов** (MSE = 0.00278)
2. **Преимущества GP:**
   - Предоставляет доверительные интервалы (оценку неопределённости)
   - Автоматически подбирает гиперпараметры ядра
   - Менее склонен к переобучению
3. **Ядерное сглаживание** проще и быстрее, но уступает в точности
