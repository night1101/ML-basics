# Регуляризация и отбор признаков: Lasso vs Ridge vs Stepwise

##  Описание задачи
Сравнение методов регуляризации для регрессии и классификации, а также демонстрация способности Lasso обнулять незначимые признаки.

**Задачи:**
1. Регрессия: предсказание цены дома с Lasso и Ridge
2. Классификация: предсказание качества вида с L1 и L2 регуляризацией
3. Демонстрация на синтетических данных (10 признаков, только 2 значимых)

##  Используемые методы
- **Lasso (L1-регуляризация)** — обнуляет коэффициенты, отбирает признаки
- **Ridge (L2-регуляризация)** — сжимает коэффициенты, но не обнуляет
- **Stepwise Forward Selection** — жадный алгоритм отбора признаков
- **Cross-Validation** — выбор оптимальных гиперпараметров
